# 智能药房管理后台 Stitch C1 全局设计规格

## 1. 使用目的

本规格只用于生成智能药房 SaaS 管理后台 UI 设计图，不包含后端、数据库、部署、账号、密码、令牌或真实患者数据。

页面以老项目 11 个一级菜单、68 个二级菜单为业务基线，并增加新系统的“机构应用配置”，共 69 个业务入口。生成工作分为三个阶段，所有阶段必须共享本规格，避免形成三套视觉系统。

## 2. 参考方向

- 主要气质参考 [Soybean Admin](https://github.com/soybeanjs/soybean-admin)：轻快、明亮、清晰。
- 信息结构参考 [Ant Design Pro](https://github.com/ant-design/ant-design-pro)：稳定的导航、内容层级和数据表格。
- 紧凑列表参考 [Pure Admin](https://github.com/pure-admin/vue-pure-admin)：适合中文管理后台的控件密度。
- 不照搬任何项目的品牌、演示数据、插画、图标排列或彩色指标卡。

## 3. C1 医疗克制版视觉方向

### 3.1 产品气质

明亮、专业、可信、工作导向。保留 Soybean Admin 的清爽感，但降低紫色、粉色和大面积多彩卡片的使用。用户应首先感受到信息清晰和操作可靠，而不是模板感或展示感。

### 3.2 颜色令牌

| 用途 | 色值 | 使用规则 |
| --- | --- | --- |
| 主色 | `#2563EB` | 当前菜单、主按钮、链接、选中态 |
| 信息色 | `#0891B2` | 接入、同步、待处理等信息状态 |
| 成功色 | `#16A34A` | 启用、成功、已完成、健康 |
| 警告色 | `#F59E0B` | 超时、待复核、临近阈值 |
| 危险色 | `#DC2626` | 删除、失败、停用、高风险确认 |
| 页面背景 | `#F4F7FB` | 工作区底色 |
| 主表面 | `#FFFFFF` | 顶栏、侧栏、表格和表单 |
| 主文字 | `#172033` | 标题和关键业务值 |
| 次文字 | `#64748B` | 描述、辅助字段和时间 |
| 边框 | `#E2E8F0` | 控件、表格和分区边界 |

禁止使用紫粉渐变、玻璃拟态、发光效果、彩色背景大卡片、装饰性圆球和大面积深色主题。橙色只用于警告，不作为普通装饰色。

### 3.3 字体与尺寸

- 中文：`Noto Sans SC` 或 `Source Han Sans CN`。
- 英文与数字：与中文共用无衬线字体，数字使用 tabular numerals。
- 页面标题：20px / 600。
- 区块标题：15px / 600。
- 正文与表格：13px–14px。
- 辅助信息：12px。
- 禁止超大标题和营销式文案。

### 3.4 应用壳层

- 顶栏 56px，白色，左侧品牌与折叠菜单按钮，右侧放全局搜索、通知和账号菜单。
- 左侧导航桌面宽 220px，白色；一级菜单分组清楚，当前项使用浅蓝背景和蓝色文字，不使用整块高饱和蓝底。
- 页签栏 36px，支持当前页签、关闭和更多菜单；不出现大量装饰图标。
- 工作区背景 `#F4F7FB`，页面内边距 16px，内容最大化利用宽度。
- 1366px 和 1440px 是主要桌面宽度；768px 使用收窄导航或抽屉；390px 只保证查询和查看，复杂生产操作可标记为桌面端完成。

### 3.5 标准列表页

```text
页面标题 + 简短业务说明                         主操作
紧凑筛选工具栏：常用条件 / 更多筛选 / 查询 / 重置
可选的窄统计条，不使用大面积指标卡
数据表格：业务主值 / 状态 / 关键时间 / 行内操作
左侧总数与选中数                         右侧分页
```

- 首屏必须以列表和筛选为主，不让新增/编辑表单长期占据主区域。
- 新增和编辑使用右侧 Drawer 或中等宽度 Dialog。
- 表格行高约 44px，表头 40px，状态使用小型标签。
- 业务名称为主值，编码为次级文字；UUID 不进入主列表。
- 行操作最多展示 2 个高频动作，其余进入“更多”菜单。
- 筛选项多于 5 个时只展示常用项，其余放“更多筛选”。

### 3.6 详情与作业页面

- 详情按订单、处方、患者、药品、金额、配送和操作记录分段。
- 审核、调剂、复核、煎煮和物流作业使用明确的主操作区，不与普通查询按钮混在一起。
- 高风险动作显示影响对象、当前状态、原因输入和二次确认。
- 时间线、状态步骤和异常原因优先使用业务中文，不暴露原始枚举。

### 3.7 导入、打印与报表

- 导入使用“模板下载 → 文件选择 → 预检 → 执行 → 结果”分步流程。
- 打印页面包含固定纸张预览、打印机选择、份数、打印结果和重打原因。
- 报表保留筛选、汇总、明细钻取和导出，不把所有报表做成同一张仪表盘。
- 图表颜色以蓝、青、绿为主，橙色仅表示风险或异常。

## 4. 页面状态

所有生成页面必须包含以下状态设计：

- 正常有数据。
- 首次加载和局部刷新。
- 空数据，提供与当前页面相关的下一步操作。
- 接口错误，展示原因和重试。
- 无权限和只读。
- 保存中、提交中、导入中、打印中。
- 长机构名、长路径、长备注和缺失值。
- 启用、停用、成功、失败、处理中和超时。

## 5. 内容与安全约束

- 只使用脱敏示例，例如“南山医院”“机构编码 HOSP-001”“处方号 RX-20260811-001”。
- 患者姓名显示“张*”，手机号显示“138****1234”。
- 不生成真实身份证、完整手机号、密码、AppSecret、Token、数据库地址、服务器 IP 或内部端口。
- 密钥只显示“已配置 / 未配置”，不显示明文。
- 不虚构系统没有的图表、AI 助手、待办数量或业务指标。
- 不删除报告中已有的筛选、表格字段、导入、导出、打印或高风险动作。

## 6. 可直接粘贴到 Stitch 的全局 Prompt

```text
请为“智能药房 SaaS 管理后台”生成一组高保真桌面端 UI，视觉方向为 C1 医疗克制版。

整体气质明亮、专业、可信、工作导向。参考 Soybean Admin 的清爽感、Ant Design Pro 的信息层级和 Pure Admin 的中文后台密度，但不要复制任何品牌或演示数据。

使用白色顶栏和侧栏、#F4F7FB 工作区、#2563EB 主色、#0891B2 信息色、#16A34A 成功色、#F59E0B 警告色、#DC2626 危险色。禁止紫粉渐变、玻璃拟态、装饰圆球、发光效果和大面积彩色指标卡。

桌面结构为 56px 顶栏、220px 左侧分组导航、36px 可关闭页签和 16px 内边距工作区。1366/1440px 优先，页面高信息密度但不拥挤。

标准列表页首屏必须是页面标题、紧凑筛选、数据表格和分页。新增/编辑使用右侧 Drawer 或 Dialog，不让编辑表单长期占据主页面。表格行高约 44px，业务名称为主值、编码为次级信息，状态使用小型语义标签，行内只显示两个高频动作，其余放入更多菜单。

页面必须覆盖加载、空数据、错误、无权限、只读、禁用、提交中和长字段状态。使用脱敏中文示例数据，不展示密码、密钥、Token、服务器地址、真实患者信息或 UUID。不虚构项目不存在的业务动作和指标。
```
