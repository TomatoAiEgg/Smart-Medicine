# 观测中间件

当前监控、日志和链路追踪默认以云服务器环境为准：

```text
47.120.55.53
```

## 组件清单

| 组件 | 用途 | 建议入口 |
| --- | --- | --- |
| Grafana | 看板入口，查看 Prometheus 指标和日志数据源 | `http://47.120.55.53:13000` |
| Prometheus | 服务、JVM、主机、容器指标采集 | `http://47.120.55.53:19090` |
| SkyWalking OAP | 链路追踪后端 | 内网访问 |
| SkyWalking UI | 服务拓扑和调用链查询 | `http://47.120.55.53:18094` |
| Loki / 日志采集组件 | 容器日志聚合 | 按实际 compose 配置 |
| node-exporter | 主机指标 | 内网或白名单 |
| cAdvisor | 容器指标 | 内网或白名单 |

## 暴露策略

- Grafana、Prometheus、SkyWalking UI 可以按需要暴露到公网。
- 暴露后必须用云防火墙限制来源 IP。
- OAP、node-exporter、cAdvisor、Loki 不建议公网开放。
- 所有默认密码必须在部署后修改。

## 服务接入要求

Java 服务接入：

- 挂载 SkyWalking Java Agent。
- 开启 Spring Boot Actuator。
- 暴露 Prometheus 指标端点。
- 日志输出包含服务名、订单号、业务动作、结果和错误原因。

前端接入：

- 前端不保存链路追踪编号。
- 前端错误反馈记录接口路径、请求时间、订单号和错误码。
- 后端通过 SkyWalking 查询对应时间窗口和 endpoint。

## 检查命令

服务器执行：

```text
cd /opt/zhyf
docker compose ps
docker compose logs --tail 100 zhyf-grafana
docker compose logs --tail 100 zhyf-prometheus
docker compose logs --tail 100 zhyf-skywalking-oap
docker compose logs --tail 100 zhyf-skywalking-ui
```

本地端口检查：

```text
Test-NetConnection 47.120.55.53 -Port 13000
Test-NetConnection 47.120.55.53 -Port 19090
Test-NetConnection 47.120.55.53 -Port 18094
```

## 日常使用

- 服务是否存活：看 Prometheus target 和 Spring Boot health。
- 接口是否慢：看 Grafana HTTP 延迟面板和 SkyWalking endpoint。
- 链路断在哪：看 SkyWalking 拓扑和调用链。
- SQL 是否慢：看数据库指标、应用慢 SQL 日志和 SkyWalking 数据库 span。
- 容器资源是否紧张：看 cAdvisor 和 node-exporter。
