# 本地开发环境

## 当前开发方式

本地开发默认：

- 前端在 Windows 本地运行。
- 后端可以在 Windows 本地 IDEA / Maven 启动。
- 中间件默认连接云服务器 `47.120.55.53`。

如果需要完全离线开发，可以临时启动 `infra/docker-compose.local-optional.yml` 中的本地 PostgreSQL、Redis、RocketMQ，但这不是默认路径。

## 本地依赖

- JDK 21
- Maven
- Node.js
- npm
- PowerShell
- Docker Desktop 可选

## 默认中间件地址

```text
PostgreSQL: 47.120.55.53:15432
Redis:      47.120.55.53:16379
RocketMQ:   47.120.55.53:9876
```

敏感密码从本机环境变量或服务器 secrets 获取，不写入仓库。

## 后端启动

常用脚本：

```text
scripts/run-gateway-local.ps1
scripts/run-auth-institution-local.ps1
scripts/run-order-service-local.ps1
scripts/run-message-service-local.ps1
```

本地启动前确认：

```text
Test-NetConnection 47.120.55.53 -Port 15432
Test-NetConnection 47.120.55.53 -Port 9876
```

## 前端启动

```text
cd frontend/admin-web
npm install
npm run dev
```

前端通过 Vite proxy 或 gateway 调用后端，不直接连接数据库和中间件。

## 本地可选中间件

只在云服务器不可用或需要离线验证时使用：

```text
docker compose -f infra/docker-compose.local-optional.yml --profile local-optional up -d
```

使用本地中间件时必须明确修改环境变量，避免误连云服务器。
