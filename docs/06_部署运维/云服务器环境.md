# 云服务器环境

本文档记录当前开发测试环境的服务器和中间件部署边界。

当前项目应用服务、中间件和观测组件部署在云服务器：

```text
47.120.55.53
```

后续新文档、联调和部署说明均以该云服务器为准。

| 项目 | 当前值 |

| 主机 | 云服务器 |
| 公网 IP | `47.120.55.53` |
| 系统 | Ubuntu |
| 部署根目录 | `/opt/zhyf` |

## 容器命名规则

项目容器统一使用 `zhyf-` 前缀，例如：

- `zhyf-postgres`
- `zhyf-redis`
- `zhyf-rocketmq-namesrv`
- `zhyf-rocketmq-broker`
- `zhyf-gateway`
- `zhyf-order-service`
- `zhyf-workflow-service`
- `zhyf-admin-web`
- `zhyf-grafana`
- `zhyf-prometheus`
- `zhyf-skywalking-oap`
- `zhyf-skywalking-ui`

禁止混用其他项目容器和数据卷。

## 安全要求

- 仓库文档不保存服务器密码、数据库密码、Redis 密码、MQ 密码、1Panel 密码。
- 敏感配置只保存在服务器 `.env`、`/opt/zhyf/secrets` 或等价的密钥目录。
- 数据库、Redis、RocketMQ 默认不对公网开放。
- Grafana、Prometheus、SkyWalking、1Panel 如需公网访问，必须由云防火墙或系统防火墙限制来源 IP。
- Docker 日志必须设置大小和保留数量限制。

## 日常检查

在服务器执行：

```text
cd /opt/zhyf
docker ps --filter name=zhyf --format "table {{.Names}}\t{{.Image}}\t{{.Status}}\t{{.Ports}}"
docker compose ps
docker compose logs --tail 100 zhyf-gateway
docker compose logs --tail 100 zhyf-order-service
docker compose logs --tail 100 zhyf-postgres
docker compose logs --tail 100 zhyf-rocketmq-broker
```

在本地检查端口连通性：

```text
Test-NetConnection 47.120.55.53 -Port 80
Test-NetConnection 47.120.55.53 -Port 13000
Test-NetConnection 47.120.55.53 -Port 19090
Test-NetConnection 47.120.55.53 -Port 18094
```
