# 中间件连接信息

本文档只记录当前开发测试环境的中间件位置和用途，不记录密码、私钥、token、数据库账号等敏感信息。

当前项目中间件运行在云服务器：

```text
47.120.55.53
```

后续本地开发、联调和部署默认使用该云服务器中间件。

## 应用配置方式

应用服务通过环境变量读取连接信息：

```text
ZHYF_DB_HOST=47.120.55.53
ZHYF_DB_PORT=15432
ZHYF_DB_NAME=zhyf_saas
ZHYF_REDIS_HOST=47.120.55.53
ZHYF_REDIS_PORT=16379
ZHYF_ROCKETMQ_NAMESRV=47.120.55.53:9876
```

密码和账号不写入本文档，部署时从服务器侧 `.env` 或 secrets 文件注入。

## 连接边界

- 本地开发可以连接云服务器中间件，但数据库、Redis、RocketMQ 不建议长期公网裸露。
- 如果临时需要公网连接，必须通过云防火墙限制来源 IP。
- 应用容器在服务器内运行时优先使用 Docker 网络内服务名访问中间件。
- 外部访问统一经 Nginx 和 gateway，不直接暴露业务服务端口。
