# 老项目 UI 截图基线

采集时间：2026-08-12

本目录按老系统实际菜单保存 11 张父级菜单展开图和 64 张子页面图。截图用于后续前端重构时核对信息密度、筛选项、表格列、状态、操作入口、分页和表单结构。

为避免保存业务隐私，数据表正文、详情值和输入框现有值已在浏览器渲染阶段遮蔽；页面标题、筛选标签、表头、状态标签、操作按钮和布局结构保留。
